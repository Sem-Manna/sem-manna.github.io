# Third-party assets

The homepage uses local SVG files, with no icon font, CDN, or runtime requests.

| Asset | Source | License |
| --- | --- | --- |
| `static/icons/email.svg` | [Bootstrap Icons: envelope](https://github.com/twbs/icons/blob/main/icons/envelope.svg) | MIT; the full notice is in `static/icons/LICENSE-bootstrap-icons.txt`. |
| `static/icons/linkedin.svg` | [Bootstrap Icons: LinkedIn](https://github.com/twbs/icons/blob/main/icons/linkedin.svg) | MIT; the full notice is in `static/icons/LICENSE-bootstrap-icons.txt`. |
| `static/icons/google-scholar.svg` | [Simple Icons: Google Scholar](https://github.com/simple-icons/simple-icons/blob/develop/icons/googlescholar.svg) | [CC0 1.0 Universal](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). |
| `static/icons/orcid.svg` | [Simple Icons: ORCID](https://github.com/simple-icons/simple-icons/blob/develop/icons/orcid.svg) | [CC0 1.0 Universal](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). |

The downloaded icons retain their original shapes; only the SVG fill colors were
set for use as standalone images. The desk-telephone SVG in `static/icons/phone.svg`
was drawn for this website and uses the site's existing accent color.

The small audience, eye, banknote, donkey, and elephant drawings in
`template/research-ornaments.html` are original SVG artwork made for this website.
The tripod telescope in `static/icons/telescope.svg` and the header's
sun/moon symbols are also original SVG artwork.

Bootstrap CSS and JavaScript retain their separate MIT license in
`static/vendor/bootstrap/LICENSE`. The cyc generator's license is in `LICENSE`.
